# Summary Method for `SeverityEstimateModel` Objects

Summarises a user-defined severity estimate model by reporting input
data dimensions, detection probability priors, timestep bounds, mapped
detection and outcome counts, and strata specifications.

## Usage

``` r
# S3 method for class 'SeverityEstimateModel'
summary(object, ...)
```

## Arguments

- object:

  An object of class
  [SeverityEstimateModel](https://accidda.github.io/SeverityEstimate/reference/SeverityEstimateModel.md).

- ...:

  Unused.

## Value

`summary.SeverityEstimateModel` returns an object of class
`SummaryEstimateModel`.
